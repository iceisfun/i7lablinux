# Operator requirement: JetKVM virtual-media boot (added mid-build, 2026-11-12)
The intent of i7lablinux: with a JetKVM attached to a lab host, an automation driver (hwlab / a future `i7labctl jetkvm ...`) can: upload the lab linux image to the JetKVM, mount it as virtual media (Disk or CD-ROM mode), power the host off, power it on, boot from lab linux (one-time boot menu or boot order), then drive the host remotely with i7labctl (ether/HTTP/ssh). With a JetKVM, lab linux becomes extremely powerful: no USB stick handling at all.
## Requirements that follow
1. The build must produce an image that boots as USB MASS STORAGE emulated by a JetKVM in BOTH modes: (a) raw disk image (GPT + ESP, UEFI and BIOS) and (b) an ISO9660 hybrid/El Torito image for CD-ROM mode. Keep the image small (initramfs-only rootfs; target <= 256 MiB if possible, document sizes) so upload is quick.
2. No persistent-disk assumption: lab linux must come up fully from RAM, read-only media, with no writes to the boot media.
3. The kernel must carry the USB mass-storage gadget side's host-visible drivers (usb-storage/uas, xhci) AND boot reliably from a USB device that appears late (initramfs waits for the root/ESP media, rdinit path).
4. i7labctl gains a `jetkvm` command group (or a documented hwlab integration): upload image, mount/unmount (Disk|CDROM), power on/off/cycle (via the JetKVM's ATX/DC control or hwlab), one-time boot hint, console screenshot, wait-for-beacon after boot, and a single combined verb `i7labctl lab-boot --jetkvm HOST --image PATH` that does the whole sequence and returns when the host's beacon appears. Prior art in the earlier prototype: docs/hwlab/JETKVM.md (JSON-RPC 2.0 methods incl. getVirtualMediaState, mountWithHTTP/Storage, POST media/mount {filename, mode: Disk|CDROM}) and host/hwlab-jetkvm. Virtual media was never exercised on a real device yet (docs/hwlab/STATUS.md): the first real run is part of the acceptance.
5. Discovery must work after boot with no IP (ether beacon) and on a VLAN.
6. Document the remote-boot procedure for the JetKVM case next to the USB-stick case (docs/REMOTE-BOOT.md).
