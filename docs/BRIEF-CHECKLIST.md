# Brief checklist (completeness audit V2, 2026-11-12)

Every bullet of the operator brief, checked against this tree: does it exist, is it tested, is it documented, and did an
end-to-end run really exercise it. **PASS** = built, tested, documented and exercised end to end in QEMU. **PARTIAL** = exists
but a part is missing, broken, or never ran end to end. **MISSING** = not there. Nothing here has run on physical hardware
yet; that is stated once here and not repeated per row (see [E2E-RESULTS.md](E2E-RESULTS.md) NOT RUN).

Evidence sources:

* E2E = [E2E-RESULTS.md](E2E-RESULTS.md) and its [transcript](e2e/transcript-20261113.txt) (91/91 checks, BIOS + UEFI, `scripts/e2e`).
* AUDIT = the supplementary QEMU runs made for this audit, [e2e/brief-audit-20261112.txt](e2e/brief-audit-20261112.txt): image
  rebuilt from this tree on the build host (`scripts/build-image --full`), one BIOS q35 guest per run, keys as available then (the public demo keys, since removed), `--link mcast:`
  segment, commands the E2E did not cover.
* UNIT = `cargo test --workspace` on the build host: **731 passed, 0 failed, 1 ignored** (the sudo-only loop test), including the new
  `crates/i7labd/tests/brief_coverage.rs`.

## What this audit changed

* New test `crates/i7labd/tests/brief_coverage.rs`: the current-release catalogue commands without an `i7labd` handler are
  pinned (`identify`, `msg`, `tui`, `tui.dump`); planned commands must not carry dead handlers; the brief's core commands
  must be served. Implementing a console command makes the first test fail on purpose until the list and this file are updated.
* [I7LABCTL.md](I7LABCTL.md): `--http` addressing rule (no host word, except `sh`; E2E open issue 7), `--retries` default (0,
  as the code and `help`), the not-served console commands.
* [REMOTE-BOOT.md](REMOTE-BOOT.md): real tab list, real `blk ls` verdict names, a note that `msg`/`identify` are not served yet
  and that VLAN tagging is not yet proven end to end.
* [e2e/brief-audit-20261112.txt](e2e/brief-audit-20261112.txt): the supplementary QEMU transcripts.
* [EXPANSION.md](EXPANSION.md): the large gaps as roadmap items.
