i7labctl key
  key management

usage: i7labctl key init|show|verify|import|export ...
transports: local   role: none

Key management. Keys are `i7k1:<role>:<64 hex>` files, mode 0600. They are found without flags in this order: --key, $I7LABCTL_KEY, $I7LABCTL_KEYDIR/<role>.key (or --keys DIR), ~/.config/i7labctl/keys/<role>.key, ./keys/<role>.key.
  key init [--dir DIR] [--force]   create admin.key, ro.key, KEYSET-ID in ~/.config/i7labctl/keys and ./keys (or DIR only); refuses to overwrite without --force, then keeps the old set in old/<date>-<ts>/
  key show [--role R] [--secret]            fingerprints and paths; --secret prints the key line after asking
  key verify <host>                         authenticate to the host and print the granted role
  key export [--role ro] [--file F] [-y]    print/copy a key line; the admin key needs --yes (it is root on every host of the set)
  key import <file> [--force]               install a key line
  key rotate                                not in v1: scripts/gen-keys --force, then scripts/bake-keys per stick

examples
  i7labctl key init
  i7labctl key show
  i7labctl key verify m900
  i7labctl key export --role ro --file ro.key

global options and exit codes: i7labctl help
