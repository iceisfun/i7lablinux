i7labctl: drive i7lablinux hosts over Ethernet frames (no IP needed) or HTTP

usage: i7labctl [global options] <command> [args]
       i7labctl --ether <mac> --cmd <wire-command> [params..]
       i7labctl help <command>

quick start
  i7labctl key init                      create your keys (found automatically from then on)
  scripts/build-usb-drive /dev/sdX       build, write and key a stick (see docs/BUILD.md); boot a host from it
  sudo setcap cap_net_raw+ep $(command -v i7labctl)    once, so raw Ethernet works without root
  i7labctl discover                      hosts booted from the stick appear within seconds
  i7labctl inv <mac>                     hardware inventory;  i7labctl shell <mac>  for a shell

global options (accepted before or after the command; after `--` nothing is parsed)
  -H, --host SEL          host selector: MAC (any NIC), IPv4, board serial, board name, hostname, alias, or a
                          unique MAC prefix of 4+ characters
  --ether MAC             use the ether transport to that NIC MAC (also the host selector)
  --cmd NAME              raw form: send wire command NAME with the remaining words as its argv (no checks);
                          NAME is a catalogue name (help ether) or a numeric id such as 0x0001
  --http IP[:PORT]        use the http transport (port 80)
  --ssh [USER@]IP         ssh transport (exec, sh, shell only)
  --transport auto|ether|http|ssh
  -i, --iface IF          lab-side interface (repeatable, or comma separated); default: every Ethernet NIC
  --vlan ID[,ID|A-B]      802.1Q tag to send with / listen on (repeatable)
  --role admin|ro         key role (default: admin if its key file exists, else ro)
  --key FILE              explicit key file (wins over --role)
  --keys DIR              key directory holding admin.key / ro.key (same as $I7LABCTL_KEYDIR; wins over it)
  --timeout SEC           whole-command timeout (default 30; streaming commands: none; 0 = none)
  --retries N             extra full handshake attempts after the session engine's own retries (default 0)
  --json                  machine output (envelope / NDJSON), see: i7labctl help json
  -q, --quiet   -v (trace)   -vv (frame trace)   --no-color (also NO_COLOR)   (pcie has its own --verbose)
  --registry FILE         registry file (default ~/.cache/i7labctl/hosts.json)
  --no-registry           ignore the registry (and its key-set check)
  -y, --yes               do not ask before destructive actions (never skips the serial of blk write)
  --link udp:LOCAL:REMOTE | mcast:GROUP:PORT
                          test transport: Ethernet frames over UDP (QEMU -netdev dgram), no CAP_NET_RAW needed
  -h, --help   -V, --version

exit codes
  0    success
  1    generic failure (the command ran but reported failure)
  2    usage error (bad option or arguments), nothing was sent
  3    a test or probe found a problem: blk read/write/verify errors or mismatches, SMART verdict FAILED
  4    no response or timeout (transport, handshake without CHALLENGE, wait timeout, ping without reply)
  5    authentication failure (server proof invalid, key unknown to the host, no key file, role too low)
  6    host not found in the registry / not reachable at L2
  7    refused by a safety rule (REFUSED from the host, or a local refusal in blk write / image write)
  8    ambiguous host selector (candidates are listed)
  9    host busy (BUSY, NOT_READY)
  10   unsupported command or version mismatch (UNSUPPORTED, planned commands)
  130  interrupted (Ctrl-C)
  255  exec, sh, shell, ssh only: i7labctl's own error (1..254 are then the remote command's exit status)

more: i7labctl help <command> | help --all | help ether | help exit-codes | help boot-keys | help json

i7labctl discover
  listen for L2 beacons, fill the registry

usage: i7labctl discover [--listen S] [--active] [--watch] [--all] [--assign MAC=IP/PFX[/GW]].. [-i IF].. [--vlan IDS]
transports: ether   role: none

Listen for L2 beacons (ethertype 0x88B5) and probe replies on every Ethernet NIC with carrier, print what was seen, and record it in the registry. Works with no IP at all and on VLANs (802.1Q tags are decoded; --vlan restricts the listen set and tags probes).
  --listen S    listen window in seconds (default 4)
  --active      also broadcast PROBE frames (at most 1 per second per NIC, 5 per run) so hosts answer within half a second; with --vlan 1-200 every id is probed on a tagged trunk
  --watch       run until Ctrl-C and print events: new, lost (silent 15 s), reboot (boot id changed), ip, state
  --all         include registry entries not seen in this run
  --assign MAC=IP/PFX[/GW]
                answer that MAC's address-less beacon with an address hint (I7LR2 signed with the admin key; I7LR1 to old sticks); at most one hint per MAC per 10 s
  --daemon      keep running and rewrite the registry every second (like --watch without output)
Beacons whose mac= differs from the Ethernet source are flagged src-mac-mismatch. A beacon tag that fails verification is shown as unverified, never trusted.

examples
  i7labctl discover
  i7labctl discover --active --listen 3
  i7labctl discover --watch -i eth1 --vlan 13
  i7labctl discover --assign 02:00:00:9d:01:57=192.0.2.195/24/192.0.2.1

global options and exit codes: i7labctl help

i7labctl ls
  list known hosts

usage: i7labctl ls [--all] [--sort mac|ip|age|board] [--state live|stale|any]
transports: local   role: none

List the hosts in the registry (no network). live = beacon within 15 s; entries older than 10 minutes are hidden unless --all. The NOTE column flags: src-mac-mismatch, v1, unverified-tag, other-keyset (the host's key set matches none of your keys: commands to it exit 5 without sending).
  --sort mac|ip|age|board   (default age)
  --state live|stale|any    (default live and stale)

examples

  i7labctl ls --state live --json
  i7labctl ls --all --sort board

i7labctl ping
  round trip, uptime, boot id

usage: i7labctl ping <host> [-c N] [-W S] [ECHO]
transports: ether, http   role: read-only key is enough

Round trip to the host over the chosen transport; prints RTT min/avg/max and the host's boot id and uptime. Exits 4 if no reply. With the ether transport the first call includes the handshake (one CHALLENGE round trip).
  -c N     number of pings (default 4)
  -W S     per-ping timeout (default 3)
  ECHO     optional text (up to 1024 bytes) the host echoes back

examples
  i7labctl ping 02:00:00:9d:01:57
  i7labctl ping m900 -c 10
  i7labctl --ether 02:00:00:9d:01:57 --cmd ping

wire command: ping (0x0001) [ECHO]

global options and exit codes: i7labctl help

i7labctl net
  NICs and configuration

usage: i7labctl net ls|set|vlan|link|confirm <host> ...
transports: ether, http   role: read-only key for reads, admin key for changes

Network interfaces and configuration.
  net ls <host> [IFACE] [--all]               R: NICs with kind, addresses, VLANs; kernel-made virtual devices (dummy0, sit0, ..) are hidden unless --all
  net set <host> IFACE (--dhcp | --ip A.B.C.D/N [--gw A.B.C.D] [--dns A,B]) [--mtu N] [--confirm SEC]   W
  net vlan add <host> IFACE VID [--ip A.B.C.D/N]   |   net vlan del <host> IFACE VID    W
  net link <host> IFACE up|down               W
  net confirm <host>                          W: keep a change made with --confirm
--confirm SEC reverts the change unless confirmed: use it over http so a wrong address does not cut you off. Over ether it is not needed (ether works with any IP state).

examples

  i7labctl net set 02:00:00:9d:01:57 eth0 --ip 192.0.2.195/24 --gw 192.0.2.1
  i7labctl net vlan add m900 eth0 13 --ip 10.13.0.5/24

i7labctl blk
  block devices, tests (write: --destructive --serial S) and disk images (image: stream a raw image onto a whole disk)

usage: i7labctl blk ls|smart|read|write|verify|image <host> ...
transports: ether, http   role: read-only key for reads, admin key for changes

Block devices: enumeration, SMART, read test, write test.
  blk ls <host> [--all]       name, size, model, SERIAL, table, filesystems, mounted, boot media, SMART verdict, and the write-safety verdict (WRITE-SAFE or UNSAFE: reasons)
  blk smart <host> DEV [--attrs]   PASSED / WARNING / FAILED / UNKNOWN with reasons, temperature, hours, NVMe wear and error counters, SATA attributes (exit 3 on FAILED); USB disks may answer 'not available (bridge)'
  blk read <host> DEV [--mb N] [--regions start,mid,end | --offset B --len B] [--bs 1m] [--direct]   READ-ONLY (default 256 MiB in three regions)
  blk write <host> DEV --destructive --serial SERIAL [--allow-boot-media] [--mb N] [--regions ..] [--offset B --len B] [--seed N]
  blk verify <host> DEV --seed N [--mb N] [--regions ..]   read-only compare against a seeded pattern
  blk image <host> DISK --file IMG --serial SERIAL --destructive [--allow-boot-media] [--yes] [--verify] [--offset N] [--resume] [--grow-last] [--no-relocate] [--verify-chunk MIB]
  blk image <host> DISK --file IMG --serial SERIAL --verify-only [--from-range N] [--skip-gpt-head] [--offset N] [--verify-chunk MIB]
      stream a raw disk image (tens of GiB, sparse is fine) onto a WHOLE disk without staging it on the host: chunked, SHA-256 per chunk and for the whole image, resumable, flow controlled, zero ranges skipped on the wire. Shows model, size, serial and the current layout and asks first (--yes skips the question, never the serial). --verify reads the disk back in bounded ranges (256 MiB per request by default, each range hashed on the host and compared with the image here; prints range i/N and MB/s, ends with 'verify OK <sha256>'; a damaged range is reported with its offset). --verify-only does only that comparison (READ-ONLY: needs --serial but not --destructive) and can be rerun any time; --from-range N continues a verify at range N; --skip-gpt-head leaves out the first 8192 bytes, which the GPT backup move rewrites after a flash. Afterwards the GPT backup is moved to the end of the disk (like sgdisk -e; --grow-last also extends the last partition, --no-relocate leaves the disk exactly as streamed) and the kernel is asked to re-read the partition table. --offset N writes the image at byte N of the disk (multiple of 4096; no GPT move). --resume continues an interrupted transfer where the host stopped.
SAFETY: blk write and blk image are the only commands that write to a disk (both go through the same host gate). It refuses locally without --destructive and --serial (exit 7) and asks for confirmation unless --yes. The host then refuses (exit 7) a disk that is mounted, held, swap, read-only, backing the running system, or under test (no override exists for those). The boot media is refused too, except when the host proves it is fully RAM-resident (root on rootfs/tmpfs/ramfs, nothing mounted, held, swapped or executing from that disk): blk ls then shows boot_media(ram-resident: --allow-boot-media) and the write needs that flag in addition to --destructive and --serial (the host keeps running from RAM; it cannot boot from that disk afterwards). A disk with a partition table or filesystem signature needs the same two flags and the real serial (see blk ls). Default is always read-only. The seed is printed (and chosen here when omitted) so blk verify can re-check after a reboot.
Exit 3 when a test finds I/O errors or mismatches or SMART says FAILED.

examples
  i7labctl blk ls 02:00:00:9d:01:57
  i7labctl blk smart m900 nvme0n1 --attrs
  i7labctl blk read m900 nvme0n1 --mb 1024
  i7labctl blk write m900 sdb --destructive --serial S3Z9NB0K123456 --mb 512
  i7labctl blk verify m900 sdb --seed 8812
  i7labctl blk image darter nvme0n1 --file win10.img --serial S5XYNX0R --destructive --verify

global options and exit codes: i7labctl help

i7labctl exec
  run a program (no shell)

usage: i7labctl exec <host> [--timeout S] [--env K=V].. [--cwd D] [--stdin F|-] [--tty] [--detach] -- CMD..
transports: ether, http, ssh   role: admin key

Run a program on the host (no shell) and stream its output. The exit status of i7labctl is the remote command's (0-254); errors of i7labctl itself (transport, auth, refused) exit 255 here. The command words must come after `--`.
  --timeout S   remote timeout (default 300, 0 = none)    --env K=V (repeatable)    --cwd DIR
  --stdin FILE|-   send a file or this terminal's stdin to the program
  --tty         run on a pty with this terminal's size
  --detach      start as a job and print the job id (see: jobs)
Shell builtins of i7labsh (ls, cat, mount, ...) are not programs: use `sh` or `exec -- i7labsh -c '...'`.

examples
  i7labctl exec 02:00:00:9d:01:57 -- dmesg
  i7labctl exec m900 --timeout 60 -- /run/test.elf --self-check
  i7labctl exec m900 --stdin script.sh -- /bin/i7labsh

wire command: exec (0x0020) [--timeout S] [--env K=V].. [--cwd D] [--tty CxR] [--detach] [--stdin] -- ARGV..

global options and exit codes: i7labctl help

i7labctl sh
  run a command line through i7labsh (alias of exec -- i7labsh -c)

usage: i7labctl sh <host> '<command line>'
transports: ether, http, ssh   role: admin key

Run a command line through the in-image shell (i7labsh): pipes, redirections, ; && ||, and its builtins (ls cat cp mv rm mkdir mount umount ip dmesg ps kill ...). Same as `exec -- i7labsh -c 'LINE'`. Exit status is the remote status.

wire command: exec (0x0020) [--timeout S] [--env K=V].. [--cwd D] [--tty CxR] [--detach] [--stdin] -- ARGV..

  interactive i7labsh on a pty

usage: i7labctl shell <host> [--term T] [--escape C] [--via ether|ssh]
transports: ether, ssh   role: admin key

Interactive i7labsh on a pty, over ether (no IP needed). The terminal goes raw; window size changes are forwarded. Local escapes after a newline: `~.` leave, `~r` reboot the host after you typed it again, `~?` list, `~~` a literal tilde (--escape CHAR changes the character, --escape '' disables).
  --term T   TERM for the remote shell (default: yours)

i7labctl ether
  raw protocol tools

usage: i7labctl ether cmds|probe|hello|sniff|frame|replay ...
transports: ether   role: none

Raw protocol tools.
  ether cmds <mac>        the host's supported commands (the cmds wire command)
  ether probe             broadcast PROBE and print replies (like discover --active, registry untouched)
  ether hello <mac>       handshake only: session parameters, role and RTT
  ether sniff [--decode] [--count N]   print lab frames (headers only; bodies are never shown)
  ether frame <hex>       decode a captured frame offline
  ether replay <mac> NAME [args..]   send a request and resend its captured REQ frames verbatim (test hook: the host must not run it twice)
The raw form `i7labctl --ether MAC --cmd NAME [params..]` sends any wire command without checks so the server's gate can be exercised.

examples
  i7labctl ether cmds 02:00:00:9d:01:57
  i7labctl ether sniff -i eth0 --decode
  i7labctl --ether 02:00:00:9d:01:57 --cmd blk.ls --all

--json output
  One JSON document on stdout (NDJSON for streams), nothing else on stdout; diagnostics go to stderr.
  success   {"ok":true,"transport":"ether","host":{"mac":..,"ip":..,"vlan":..,"serial":..,"boot":..},
             "cmd":"inv","rtt_ms":0.8,"data":<the server's JSON exactly>}
  failure   {"ok":false,"cmd":"blk.write","error":{"code":"REFUSED","status":5,"exit":7,
             "message":"..","reasons":["mounted",..]}}
  codes     the server status names (EPERM, BAD_ARGS, UNSUPPORTED, BUSY, REFUSED, NOT_FOUND, IO, TIMEOUT, ..)
            plus E_USAGE E_TRANSPORT E_TIMEOUT E_AUTH E_NOHOST E_AMBIGUOUS E_SAFETY E_FAILED
  streams   exec, logs -f, blk read/write/verify, discover --watch print one event per line:
            {"event":"stdout","data":".."}  ({"b64":..} for non-UTF-8)  {"event":"progress",..}
            and end with {"event":"result","ok":true,"exit":0}
  ls and discover print {"ok":true,"data":{"hosts":[..]}}. MACs are lower case with colons, times unix seconds.

one-time boot menu keys (to boot the lab linux stick on a machine; the list is a convenience, check the machine)
  Dell F12 | HP Esc then F9 | Lenovo F12 (ThinkCentre) | Intel NUC F10 | ASUS F8 (desktop) or Esc (laptop)
  MSI F11 | Gigabyte F12 | ASRock F11 | Supermicro F11 | Acer F12 | Surface: hold Volume-Down while pressing power
Secure Boot must be off (the image is not signed). Remote boot procedure: docs/REMOTE-BOOT.md.
